# Konkani Starter Glossary 🗣️📚

A community-driven, open-source glossary for Konkani (कोंकणी) language revitalisation.

## About
This repository contains a 200-entry starter glossary of Konkani vocabulary with example sentences, created in collaboration with 15 volunteer native speakers. It is part of a broader language revitalisation project aimed at building free learning resources for the Konkani-speaking community.

## Data Format
The glossary is available in CSV format at [`data/glossary.csv`](data/glossary.csv).

Each entry has 8 fields:
1. **No.** — entry identifier
2. **Konkani (Devanagari)** — standard orthography
3. **Roman** — ISO 15919-inspired transliteration
4. **English** — closest equivalent gloss
5. **POS** — part of speech
6. **Category** — semantic domain
7. **Example (Konkani)** — natural usage in Devanagari
8. **Example (English)** — translation

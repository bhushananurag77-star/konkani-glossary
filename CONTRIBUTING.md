# Contributing to Konkani Starter Glossary

धन्यवाद! Thank you for your interest in contributing.

## Who Can Contribute
- Native or fluent Konkani speakers
- Linguists and language documentation specialists
- Anyone passionate about language revitalisation

## How to Contribute

### 1. Glossary Entries
- Open the [Google Sheet](https://docs.google.com/spreadsheets/d/1Zs9U4bF7yt0LaJfDaeLixEP-CBnhMeG0mdzB0VM4k1U/edit) and add suggestions as comments
- Or open a GitHub issue with your proposed entries
- Follow the existing format: Devanagari + Roman + English + POS + Category + Example

### 2. Audio Recordings
- Read the [Recording & Consent Guidelines](https://docs.google.com/document/d/1382UlHeTwecIXGsnLR8qjQW5Zcul8ndH7Hktlo2mxOs/edit)
- Contact a coordinator to be added as a Speaker
- Submit recordings following the file-naming convention

### 3. Code & Data
1. Fork this repository
2. Create a branch (`git checkout -b feature/my-contribution`)
3. Make your changes
4. Commit (`git commit -m 'Add description'`)
5. Push (`git push origin feature/my-contribution`)
6. Open a Pull Request

### 4. Issues & Suggestions
Use [GitHub Issues](https://github.com/bhushananurag77-star/konkani-glossary/issues) for:
- Bug reports (data errors, broken links)
- Feature requests (new categories, dialect support)
- General discussion

## Guidelines
- Use standard Goan Konkani orthography (Devanagari)
- Provide Roman transliteration for all entries
- Include example sentences that are natural and culturally appropriate
- Respect speaker consent and privacy choices

## Review Process
1. Coordinator reviews contributions for accuracy
2. Native speakers verify entries
3. Approved entries are merged into the main glossary

## Code of Conduct
This project follows a simple rule: **be respectful**. We are building a community resource. Treat all contributors with kindness. Harassment, discrimination, or disrespectful behaviour will not be tolerated.

गोंयची कोंकणी, उत्तरायेची कोंकणी, काणडा कोंकणी — सगळीं येवकार!
(Goan Konkani, Uttara Konkani, Canara Konkani — all are welcome!)
